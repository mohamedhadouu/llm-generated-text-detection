# LLM-Generated Text Detection

Detect whether an essay was **written by a student or generated by a Large Language Model (LLM)**, using a Transformer encoder trained from scratch with TensorFlow / Keras.

![Python](https://img.shields.io/badge/Python-3.10-blue) ![TensorFlow](https://img.shields.io/badge/TensorFlow-Keras-orange) ![Task](https://img.shields.io/badge/Task-Text%20Classification-green)

## Dataset

- **Kaggle competition "LLM – Detect AI Generated Text"**: 1,378 student essays (`train_essays.csv`)
- **DAIGT v2 external dataset** (`train_v2_drcat_02.csv`): 44,868 human and LLM-generated essays
- Combined: **46,246 essays**, split 80% train / 20% validation

## Method

1. **Exploratory analysis**: class balance, prompt distribution, essay length (mean + 1 std ≈ 716 words)
2. **Tokenization**: Keras `Tokenizer` (vocabulary of 30,000 words, `<UNK>` token), sequences padded/truncated to **512 tokens**
3. **Model**: Transformer encoder built from scratch
   - Token embedding (dimension 128)
   - **6 Transformer blocks** with multi-head attention written from scratch (scaled dot-product attention, 8 heads), feed-forward dimension 512
   - Layer normalization and dropout
   - Global average pooling and a dense softmax classifier (human vs. LLM)
4. **Training**: 1 epoch, batch size 32 (accuracy 94.4% on train, 98.96% on validation)
5. **Evaluation**: accuracy, precision, recall, F1, ROC-AUC, classification report and confusion matrix
6. **Inference demo**: the notebook classifies new texts (one human-written, one LLM-generated example)

## How to run

The notebook was developed on **Kaggle** (GPU). To reproduce:

1. Open the notebook on Kaggle and add the two datasets:
   - `llm-detect-ai-generated-text` (competition data)
   - `daigt-v2-train-dataset`
2. Run all cells.

To run locally:

```bash
git clone https://github.com/mohamedhadouu/llm-generated-text-detection.git
cd llm-generated-text-detection
pip install tensorflow keras-core keras-nlp pandas numpy scikit-learn seaborn matplotlib
jupyter notebook
```

Then update `DATA_DIR` in the notebook to point to your local copy of the data.
